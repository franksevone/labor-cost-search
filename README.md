# ระบบค้นหาบัญชีค่าแรงงานก่อสร้าง

เครื่องมือค้นหาราคาค่าแรงงานก่อสร้างจากเอกสาร **บัญชีค่าแรงสำหรับถอดแบบคำนวณราคากลางงานก่อสร้าง**
(หนังสือกรมบัญชีกลาง ด่วนที่สุด ที่ กค 0433.2/ว 480 ลงวันที่ 26 มิถุนายน 2569)

## 🌐 เวอร์ชันออนไลน์

🔗 **https://franksevone.github.io/labor-cost-search/**

(ใช้งานได้ทุกเครื่อง ไม่ต้องดาวน์โหลดไฟล์ — โฮสต์บน GitHub Pages)

## วิธีใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้องต่ออินเทอร์เน็ต)

- **ช่องค้นหา** — พิมพ์คำค้น เช่น "เสาเข็ม" "ฉาบปูน" "ท่อ PVC" "กระเบื้อง" "ทาสี"
- **ค้นหาคำพ้อง/คำย่อ** — เช่น `คสล` = คอนกรีต, `พีวีซี` = PVC, `เมทัลชีท` = Metal Sheet, `ยิปซัม` = ยิบซั่ม, `บล็อก` = บล๊อก/บล็อค (มีกลุ่มคำพ้อง ~150 กลุ่ม ดูได้ใน `index.html`)
- **หมวดหมู่** — กรองตามหมวดหลัก (1 งานโครงสร้างวิศวกรรม, 2 งานสถาปัตยกรรม, 3 งานระบบสุขาภิบาลและดับเพลิง, 4 งานระบบไฟฟ้าและสื่อสาร, 5 งานระบบปรับอากาศและระบายอากาศ)
- **ประเภท** — กรองตามประเภทย่อยภายในหมวดที่เลือก (เช่น งานหลังคา, งานฝ้าเพดาน, งานเดินท่อ PVC ระบบระบายน้ำ)

ผลการค้นหาแสดงเป็น**ตารางแบบเดียวกับเอกสารต้นฉบับ** (ลำดับที่ | รายการ | หน่วย | ค่าแรง/หน่วย (บาท) | หมายเหตุ)
โดยมีหัวข้อย่อยในตาราง (หมวดย่อยสีทอง, กลุ่มภาษาอังกฤษสีฟ้า, กลุ่มรายการสีฟ้าอ่อน) คำที่ค้นจะไฮไลต์สีเหลือง

**เลือกหลายรายการ + พิมพ์สรุป** — ติ๊ก ☑ ที่รายการที่ต้องการ (สถานะจำไว้ในเบราว์เซอร์ คงอยู่ข้ามการค้นหา
และเปิดหน้ามาใหม่) แล้วกดปุ่ม **🖨 พิมพ์สรุป** ด้านล่าง เพื่อเปิดหน้าพิมพ์สรุปเฉพาะรายการที่เลือก
เรียงลำดับที่ให้อัตโนมัติ จัดกลุ่มตามหมวด/ประเภท เหมาะสำหรับนำไปถอดแบบคำนวณราคากลาง

## ไฟล์ในโฟลเดอร์

| ไฟล์ | คำอธิบาย |
| --- | --- |
| `index.html` | หน้าเว็บระบบค้นหา + เลือกรายการ/พิมพ์สรุป (เปิดได้ทันที) |
| `data.js` | ข้อมูลทั้งหมดที่ระบบค้นหาใช้ |
| `data.json` | ข้อมูลโครงสร้างเดียวกันในรูปแบบ JSON (สำหรับนำไปใช้ต่อ) |
| `build_data.py` | สคริปต์แปลงข้อมูลจาก PDF → JSON (ใช้อ่านเมื่อต้องการอัปเดตข้อมูล) |
| `extracted.txt` | ข้อความที่แยกได้จาก PDF ตามหน้า |
| `CONTEXT.md` | สรุปทุกอย่างในโฟลเดอร์ (โครงสร้าง, pipeline, ประวัติการแก้, การ deploy) — อ่านก่อนเริ่มงาน |
| `บัญชีค่าแรง...pdf` | ไฟล์ต้นฉบับ |

## ข้อมูล

- หมวดหมู่ 5 หมวด · ประเภท 104 ประเภท · รายการ 1,285 รายการ · ราคา 1,471 รายการ
- โครงสร้างข้อมูล: หมวดหมู่ → ประเภท → รายการ → ราคา (หน่วย / ราคา / หมายเหตุ)
- หมายเหตุ: เอกสารต้นฉบับมีข้อผิดพลาดการพิมพ์บางจุด (เช่น รหัส "2.68" ที่จริงคือ "2.6.8")
  สคริปต์ได้แก้ให้แล้ว; ราคาเป็น "ค่าแรง" ไม่รวมค่าวัสดุ ยกเว้นที่ระบุไว้ในหมายเหตุ

## การสร้างข้อมูลใหม่ (ถ้าต้องการ)

```bash
.venv/Scripts/python.exe build_data.py
```

ต้องมี Python และติดตั้ง PyMuPDF ไว้ใน `.venv` แล้ว (`py -m venv .venv` + `pip install PyMuPDF`)
